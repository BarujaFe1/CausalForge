# CausalForge — Product Roadmap

## Phase 0 / MVP
- Synthetic operations dataset
- Optional upload path (planned UI)
- Intervention selection
- Assumption checklist
- Simple Diff-in-Diff
- Basic matching
- Impact report with limitations + decision memo

## Phase 2
- Propensity score
- Visual DAG canvas
- Placebo tests
- Sensitivity analysis
- Method comparison panel

## Phase 3
- Reproducible notebooks
- Experiment API
- Real metrics integrations
- Case-study library

## Out of scope
Promising automatic causality. The product must emphasize hypotheses, limitations and responsible use.
